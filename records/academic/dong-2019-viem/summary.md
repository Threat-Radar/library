## Overview

**A stub: not read in full.** Presents VIEM, a system that extracts vulnerable software names and versions from CVE summaries and third-party vulnerability reports and compares them with NVD's structured entries. Over 78,296 CVE IDs and 70,569 reports, it finds that inconsistent vulnerable versions are common and that fewer than 60 percent of reports strictly match NVD. Cited by tmodel RPT-0004 (tmodel#38): published evidence that affected-version data disagrees between CVE text, vulnerability reports and NVD (dimension 5, Q4).
