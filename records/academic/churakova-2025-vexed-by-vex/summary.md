## Overview

**A stub: not read in full.** A study of how consistently seven VEX-producing container scanners (Trivy, Grype, DepScan, Docker Scout, Snyk, OSV-Scanner and Vexy) report vulnerabilities for the same images, using Jaccard and Tversky similarity over three datasets built from Docker Hub images. It finds low consistency and identifies differences in the vulnerability databases queried as the largest factor. Cited by tmodel RPT-0004 (tmodel#38): published evidence that container scanners disagree on the same images and that database differences drive the disagreement (dimension 5, Q4).
