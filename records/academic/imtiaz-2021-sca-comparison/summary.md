## Overview

**A stub: not read in full.** A case study that runs nine software composition analysis tools on OpenMRS, a web application built from Maven and npm projects, and compares their reports. The counts of vulnerable dependencies and of distinct vulnerabilities vary widely between tools, and the authors point to the accuracy of each tool's vulnerability database as the main differentiator. Cited by tmodel RPT-0004 (tmodel#38): published evidence that SCA tools disagree on the same project and on affected version ranges (dimension 5, Q4).
