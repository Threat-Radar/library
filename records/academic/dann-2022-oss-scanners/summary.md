## Overview

**A stub: not read in full.** A study of how modifications common in Java development (re-compilation, re-bundling, metadata removal and re-packaging) affect open-source vulnerability scanners, based on 7,024 Java projects at SAP. It evaluates OWASP Dependency-Check, Eclipse Steady, GitHub Security Alerts and three commercial scanners, and presents Achilles, a test suite of 2,505 test cases. Cited by tmodel RPT-0004 (tmodel#38): published evidence on scanner precision and recall and on false positives from CPE-based matching (dimension 5, Q4).
