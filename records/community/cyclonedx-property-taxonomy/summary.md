## Overview

**A stub: not read in full.** The official registry of CycloneDX property namespaces and names, kept in a GitHub repository, with the naming rules for custom properties and one page per registered namespace. Its cdx:device namespace defines names for hardware attributes such as quantity, function, location, device type, serial number, SKU, lot number, production timestamp, MAC address, certifications and GS1 keys, and the registry also lists namespaces registered by other organisations, such as BSI's bsi namespace. Cited by tmodel RPT-0004 (tmodel#38): the cdx:device property names, the only CycloneDX 1.7 vocabulary for hardware details, in RPT-0004 section 2 (HBOM).
