## Overview

**A stub: not read in full.** Defines VERS, a URI syntax of the form vers:<type>/<constraints> for writing a software package version range compactly instead of listing versions, plus a JSON schema for defining per-ecosystem VERS types that state how versions compare. Release 1.2.1 covers linear versioning only, registers two types (npm and pypi), and is the text approved for submission to Ecma as a first edition. Cited by tmodel RPT-0004 (tmodel#38): status and scope of the vers range syntax (draft Ecma standard, linear versioning only, two registered types), and the range syntax CycloneDX uses for affected versions.
