## Overview

**A stub: not read in full.** The SWHID specification defines SoftWare Hash IDentifiers: intrinsic identifiers of the form swh:1:<type>:<id> for file contents, directories, revisions, releases and snapshots, each computed as a SHA-1 hash over a git-like serialization of the object, plus qualifiers that add context such as origin, path, or line and byte ranges. Version 1.2 is the text adopted by ISO/IEC JTC 1 under the PAS procedure and published as ISO/IEC 18670:2025. Cited by tmodel RPT-0004 (tmodel#38): Table 3's SWHID row (object types, SHA-1 serializations, qualifiers), its ISO status, and its documented defects (directory mode text, submodules).
