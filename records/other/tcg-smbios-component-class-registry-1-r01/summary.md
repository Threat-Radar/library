## Overview

**A stub: not read in full.** TCG registry that defines how data from SMBIOS structures for a finite set of components is encoded in the componentIdentifier fields of a Platform Certificate (Platform Certificate Profile 1.1 or later), so that components can be identified through SMBIOS and checked against the certificate. It includes a notation for reading SMBIOS fields, worked examples, and methods for reading SMBIOS data on Linux and with Windows PowerShell. Cited by tmodel RPT-0004 (tmodel#38): listed with the TCG and PCIe-based class registries as a way to fill Platform Certificate component fields from device data.
