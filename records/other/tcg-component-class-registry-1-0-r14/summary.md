## Overview

**A stub: not read in full.** TCG registry of componentClassValue codes that identify the type of a component listed in a TCG Platform Certificate (version 1.1 or later) when the componentClassRegistry field names the tcg-registry-componentClass-tcg OID. Its class table covers kinds such as processors (CPU, GPU, SoC), chassis, controllers including BMCs, memory, storage, network adapters, cooling and firmware. Cited by tmodel RPT-0004 (tmodel#38): the class vocabulary for hardware Component kinds (Table 4b; mapping row on component kind).
