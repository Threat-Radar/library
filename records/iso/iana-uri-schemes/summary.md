## Overview

**A stub: not read in full.** IANA's registry of Uniform Resource Identifier scheme names records each scheme's status (permanent, provisional or historical), template, reference and an optional CRI scheme number, under the registration procedures of RFC 7595. It holds provisional entries for identifier schemes used in software composition, including pkg (purl), gitoid, swh, swid and swidpath. Cited by tmodel RPT-0004 (tmodel#38): the status of identifier URI schemes (pkg, gitoid, swh, swid and swidpath are all provisional).
