## Overview

**A stub: not read in full.** The IANA registry of textual names for hash functions, created in 2006 with RFC 8122 as its current reference, which lists each name with its object identifier and defining RFC. It holds nine names (md2, md5, sha-1, sha-224, sha-256, sha-384, sha-512, shake128 and shake256), and a new entry needs a standards-track RFC that updates or obsoletes RFC 3279. Cited by tmodel RPT-0004 (tmodel#38): the hash-name registry that CISA's 2026 minimum elements point SBOM authors to; RPT-0004 Phase 1 checked which format hash names match it.
