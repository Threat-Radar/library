## Overview

**A stub: not read in full.** ISO Guide 69:1999 set out principles and guidelines for using ISO's Harmonized Stage Code system, the numeric codes (such as 60.60 or 90.60) that record a deliverable's stage in development, publication, review or withdrawal. ISO withdrew the guide in 2014; the stage codes remain in use and are listed on ISO's stage-codes page. Cited by tmodel RPT-0004 (tmodel#38): the meaning of ISO stage code 90.60 (close of review) in RPT-0004 section 1.3.
