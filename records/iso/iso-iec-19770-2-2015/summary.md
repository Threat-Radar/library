## Overview

**A stub: not read in full.** ISO/IEC 19770-2:2015 specifies software identification (SWID) tags, XML records that identify and describe software so that tag producers (platform, software and tag tool providers) and tag consumers (software consumers and IT discovery tools) can manage it. This second edition replaced ISO/IEC 19770-2:2009.
