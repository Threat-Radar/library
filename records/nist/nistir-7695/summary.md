## Overview

**A stub: not read in full.** NIST IR 7695 specifies CPE 2.3 naming: the well-formed name data model for classes of IT products, and the rules for converting these names to and from two machine-readable forms, a URI binding compatible with CPE 2.2 and a formatted string binding. It also sets the conformance requirements for products that implement CPE naming.
