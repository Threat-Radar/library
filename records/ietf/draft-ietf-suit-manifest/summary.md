## Overview

**A stub: not read in full.** This IETF SUIT working group draft defines a CBOR manifest format, protected with COSE, that tells a recipient (chiefly an IoT device receiving firmware) where to find code or data, which devices it applies to, and which sequences of operations to run to check, install and invoke it. Revision 37 is intended for the Standards Track and is waiting in the RFC Editor queue. Cited by tmodel RPT-0004 (tmodel#38): firmware identity fields (image digest and size, compatibility-only vendor and class identifiers, the anti-rollback sequence number) and firmware components for Table 4.
