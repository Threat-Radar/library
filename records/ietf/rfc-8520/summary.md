## Overview

**A stub: not read in full.** RFC 8520 specifies Manufacturer Usage Descriptions (MUD): a device emits a MUD URL (by DHCP, LLDP or an X.509 certificate extension), and a MUD manager uses it to fetch a MUD file, written to a YANG model, in which the manufacturer says what access and network functionality the device needs to work. Its initial focus is access control. Cited by tmodel RPT-0004 (tmodel#38) only as the file that RFC 9472 extends (section 6).
